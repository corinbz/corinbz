# Hi, I'm Corin Craciun

**Machine operator by day · finishing Codam (42 Amsterdam) on the side · C / C++ on Linux**

I'm most interested in what happens underneath the abstractions: how a shell
turns a line of text into processes, how an HTTP server juggles hundreds of
sockets on one thread, how a ray hits a wall. My focus is systems programming,
infrastructure and compilers.

Combining shift work with 42's peer-learning model has taught me to manage my

breaks, understand what's actually happening, fix the cause rather than the
